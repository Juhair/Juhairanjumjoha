# Juhair Anjum Joha — IT & Technology Portfolio

## Files
- `home.html` — main homepage with the developer/IT command-center design
- `home.css` — homepage styling, responsive layout, laptop/code visuals and animations
- `home.js` — loader, mobile navigation, reveal animations and active section navigation
- `blog.html`, `blog.css`, `blog.js` — blog page
- `contact.html`, `contact.css`, `contact.js`, `contact.php` — contact page
- `profile.jpg` — original profile image
- `profile-cutout.png` — transparent cutout used on the homepage so there is no rectangular image background
- `images/` — blog image folder; keep `erp.jpg`, `marketing.jpg` and `career.jpg` here when deploying

## Start
Open `home.html` in a browser.

The homepage intentionally uses CSS-built programming visuals (terminal, Python code, stack cards and laptop) so it does not depend on extra background images.
